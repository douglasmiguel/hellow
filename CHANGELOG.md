# Changelog

## 0.3.0 — 2026-10-08

- Added up to five configurable currency conversions with editable amounts and currency pairs, ordering, and removal in Settings.
- Matched currency cards to world-clock sizes, placed the groups side by side with a separator, and added currency flags and two-decimal values.
- Added a refresh spinner and fresh-rate requests on every new tab, with locally cached rates available offline.
- Added currency flags to Settings selectors, including the EU flag for EUR.
- Added access to api.frankfurter.dev for optional currency-rate requests and updated privacy and store submission materials.

## 0.2.1 — 2026-10-05

- Prepared the stable Hellow release and Chrome Web Store submission materials.
- Includes 100 background choices and 10 clock fonts.
- Removed beta branding and the personal name placeholder.
- Added a repeatable checked release ZIP workflow.

## 0.2.0-beta.1 — 2026-08-25

- Expanded the background selector to 20 choices: Daily mix plus 19 bundled CC0 photos.
- Added optimized background thumbnails for a responsive settings panel.
- Added persistent, keyboard-accessible world-clock reordering.
- Documented all bundled photo sources and licensing.
- Marked the Chrome package as Hellow Beta.
